# 🎓 College Placement & Skill-Gap Analytics

An end-to-end data analytics project examining the core drivers of campus recruitment success and corporate talent bottlenecks.

## 🚀 Executive Summary
Why do some engineering graduates land high-paying roles while others struggle, despite similar CGPAs? This project analyzes 1,000+ student profiles, technical interview scores, internship records, and live job market requirements to uncover the true determinants of placement success.

---

## 📈 Key Insights
1. **Beyond CGPA:** While a solid academic baseline is required, technical interview performance and aptitude scores act as the ultimate conversion levers for offers.
2. **The Internship Multiplier:** Students who completed 2 or more structured internships saw up to a **40% increase** in placement success rates.
3. **Talent Bottlenecks:** High corporate demand for niche tools like Cloud/AWS and Advanced SQL significantly outpaces current student training availability.
